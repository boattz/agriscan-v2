# แหล่งอ้างอิงเกณฑ์พืช (Crop Criteria Sources)

เอกสารนี้รวบรวม **แหล่งปฐมภูมิที่น่าเชื่อถือ** สำหรับค่า pH / EC / อุณหภูมิ / ความชื้น ของแต่ละชนิดพืช
ใช้เพื่อ vet ค่าใน `dashboard/crops.js` (และสำเนาใน `esp32/agriscan/dashboard.h`)

> หมายเหตุ: เอกสารบางฉบับเข้าถึง PDF ต้นฉบับจากเครื่องมือไม่ได้ (403/block) — จึงอ้างชื่อ/URL/ตารางไว้ให้ตรวจสอบภายหลัง
> **เกณฑ์ EC ที่ใช้ flag "ดินเค็ม" = เกณฑ์ความเค็ม S1 ของกรมพัฒนาที่ดิน (LDD)** — ข้าว/ข้าวโพด <2 dS/m (S1 เหมาะสูงสุด)
> พืชที่ LDD ตาราง/เล่ม 28 ไม่ครอบคลุม (มันฝรั่ง มันสำปะหลัง หอม กระเทียม แตงโม ฟักทอง ผัก ฝรั่ง) → ใช้ค่าจากเอกสารวิชาการเน้นปลอดภัย — **ไม่ได้ใช้ FAO 29 เป็นเกณฑ์หลักอีกต่อไป** (เคยประเมินไว้แต่ผู้ใช้เลือกกลับมาใช้ LDD)

## 1. กรมพัฒนาที่ดิน (Land Development Department, LDD) — แหล่งหลัก

| อ้างอิง | ชื่อเอกสาร | ครอบคลุมชนิด |
|---|---|---|
| LDD ตาราง 3 | ศักยภาพการให้ผลผลิตพืชเศรษฐกิจของชุดดิน — ตารางที่ 3 (ข้าว) ดัดแปลงจากบัณฑิตและคำรณ 2542 | ข้าว 🌾 |
| LDD ตาราง 4 | เรื่องเดียวกัน — ตารางที่ 4 (ข้าวโพด) | ข้าวโพด 🌽 |
| LDD ตาราง 5 | เรื่องเดียวกัน — ตารางที่ 5 (มันสำปะหลัง) | มันสำปะหลัง 🌱 |
| LDD เล่ม 28 | คู่มือการจำแนกความเหมาะสมของดินสำหรับพืชเศรษฐกิจ (กองสำรวจและจำแนกดิน) — **เฉพาะไม้ผล/ยาง** | ยางพารา, ลำไย, ลิ้นจี่, ทุเรียน, มังคุด, ส้มโอ, ฝรั่ง, พุทรา |
| LDD ตาราง 15 | เกณฑ์ความอุดมสมบูรณ์ของดิน (กองสำรวจดิน, 2523) — P/K ต่ำ-กลาง-สูง | ทุกชนิด (NPK) |

**URL อ้างอิง (ตรวจสอบภายหลัง):** `https://www.ldd.go.th` · ลิงก์ตาราง 15: `e-library.ldd.go.th/library/flip/bib10134f/files/basic-html/page83.html`

- **เกณฑ์ EC (S1):** ข้าว ตาราง 3 S1 <2 dS/m · ข้าวโพด ตาราง 4 S1 <2 dS/m — เป็นค่าความเค็ม "เหมาะสูงสุด" ของกรมฯ
- **NPK (N/P/K) รายพืช:** baseline = LDD ตาราง 15 (ระดับธาตุในดิน: P ต่ำ <10 / กลาง 10–25 · K ต่ำ <60 / กลาง 60–90 mg/kg — เป็นการจัดชั้นความอุดมสมบูรณ์ของดิน ไม่แยกพืช) ระบบใช้ค่า baseline แล้วปรับ trigger แยกรายพืชตามความต้องการธาตุของพืช — เช่น ข้าวโพด/หอม/กระเทียม/ผัก N สูง · มันสำปะหลัง/ทุเรียน/มันฝรั่ง/มังคุด K สูง · มันสำปะหลังทน N ต่ำ — แหล่งปรับ: คำแนะนำปุ๋ยรายพืช (กรมวิชาการเกษตร/DOAE) — **ค่าที่ต่างจาก baseline คือจุดที่ระบบจะเตือน/แนะนำให้ใส่ปุ๋ย ไม่ใช่การจัดชั้นดิน**

## 2. FAO 29 (อ้างอิงประกอบ — ไม่ใช่เกณฑ์หลัก)

- Irrigation & Drainage Paper 29 (Ayers & Westcot, 1985) ตารางที่ 4 — ECe 0% yield-loss: ข้าว 3.0 · ข้าวโพด 1.7 · มันฝรั่ง 1.7 · หอม 1.2 · ส้ม 1.7 dS/m
- **ใช้เป็นข้อมูลเปรียบเทียบ/ขอบเขต** ในรายงานประกอบเท่านั้น (ค่าในระบบปัจจุบันใช้ LDD S1)

## 3. เอกสารวิชาการรายชนิด (เมื่อ LDD ไม่ครอบคลุม)

- **CIP / FAO (มันฝรั่ง):** pH 5.2–6.0 S1 ควรสุด, 5.0–7.0 ทนได้; เก็บเกี่ยว 15–28°C
- **AVRDC/PlantVillage (หอม กระเทียม):** หอม pH 6.0–6.8, 13–24°C; กระเทียมเจริญ 9–28°C
- **UF/IFAS, FAO (ฝรั่ง):** pH 4.5–9.4, ECe ~2 (ทนได้ถึง ~5–6); ช่วงเหมาะ 23–28°C
- **Winrock FACT Sheet 98-03 / ICAR arid zone (พุทรา):** ทนด่าง (pH ~9), ทนร้อน ~50°C → `temp.max 45`
- **RRISL/DOAE (ยางพารา):** pH 4.5–6.5/เหมาะ 5.5–6.5; ไวต่อเค็มมาก ~1
- **DOAE/khlangkaset (ทุเรียน มังคุด ลำไย ฯลฯ):** `https://khlangkaset.doae.go.th` — การจัดการดิน/น้ำ

**เชิงอรรถ**
¹ ข้าวโพด `ph.max 8.4 → 7.8` — เดิมสงสัยว่าเป็นเทมเพลตจากตารางข้าว (ข้าวโพดทนด่างน้อยกว่า) → แก้เป็น 7.8 (ขอบบนช่วง S2 ของตาราง 4 ตาม comment ใน crops.js) — ยัง `conf medium` ควรยืนยันกับ PDF ตาราง 4

**pH ปรับให้ตรงแหล่ง (รอบล่าสุด):**
- ยางพารา `optMin 5.6→5.5` — ให้ตรง comment (เล่ม 28 เหมาะ 5.5–6.5) · หอมหัวใหญ่ `optMax 7.0→6.8` — ให้ตรง AVRDC (6.0–6.8)
- แตงโม `opt 6.0–7.0→5.7–7.2` — ให้ตรง comment (เอกสารวิชาการ เหมาะ 5.7–7.2)
- ฝรั่ง `min/max 5.0–7.0→4.5–8.5` — ตาม UF/IFAS (ทน 4.5–9.4) แต่ alert แค่ช่วง 4.5–8.5 กัน false alarm ช่วงด่างจัด
- พุทรา `max 8.0→8.5` — LDD เล่ม 28 ระบุ S2–S3 5.0–8.0 แต่ Winrock ระบุทนด่าง ~9 จึงเผื่อเป็น 8.5
² มันสำปะหลัง `ec 3 → 1.0` — เดิมเป็นค่าผิดพลาดที่สุดทั้งไฟล์ (สูงสุด ทั้งที่จริงอ่อนไหว); ค่าใหม่ 1.0 เป็นตัวเลขจากงานวิชาการ ยังไม่มีปฐมภูมิชื่อดัง → **conf low**
